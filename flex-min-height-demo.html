原理解释

问题根源

问题出现在嵌套的 flex 容器中。当一个 flex 子项本身也是 flex 容器时， 它的 min-height 默认值是 auto，会被其内容撑开。

关键场景：外层 flex 容器 → 中间层 flex 子项（也是 flex 容器）→ 内层滚动区域。
如果中间层没有 min-height: 0，它会被内容撑开，导致外层容器溢出。

结构示意

<div class="outer"> /* 固定高度的 flex 容器 */ <div class="header">...</div> <div class="middle"> /* flex:1 的子项，也是 flex 容器 */ <div class="scroll-area"> /* 需要滚动的区域 */ ...很多内容... </div> </div> <div class="footer">...</div> </div>

解决方案

设置 min-height: 0 可以覆盖默认的 auto 值， 让 flex 子项可以收缩到比其内容更小的尺寸，从而让 overflow: auto 生效。

.middle { flex: 1; /* 占据剩余空间 */ min-height: 0; /* 关键！允许收缩到比内容更小 */ display: flex; flex-direction: column; } .scroll-area { flex: 1; overflow: auto; /* 内容溢出时显示滚动条 */ }

flex:1 的含义

flex: 1 是以下三个属性的简写：

flex: 1; /* 等同于 */ flex-grow: 1; /* 可以放大 */ flex-shrink: 1; /* 可以收缩 */ flex-basis: 0%; /* 基础尺寸为0 */

常见应用场景

这个技巧在以下场景特别有用：

  • 固定头部/底部，中间内容区域可滚动的布局
  • 侧边栏 + 主内容区域的布局
  • 嵌套的 flex 容器中需要滚动的区域
  • 聊天界面、列表页面等需要局部滚动的场景

水平方向同理

如果是水平方向的 flex 布局（flex-direction: row）， 则需要设置 min-width: 0 来解决类似问题。
